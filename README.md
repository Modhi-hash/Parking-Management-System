# 🅿️ Parking Management System

A desktop application built using **Java Swing**, **MySQL**, and **Maven**. This system provides a simple, intuitive interface for users to search for available parking spots, select zones/floors, choose additional vehicle services, and manage their bookings.

---

## ✨ Features

* 🔐 **User Authentication:** Sign up and log in securely.
* 🚗 **Spot Reservation:** Search and view real-time availability of parking spots across different zones and floors.
* 🛠️ **Additional Services:** Add optional services such as *Car Wash*, *EV Charging*, and *Oil Change* during booking.
* 📋 **Booking Management:** View booking history, update selected services, or cancel existing reservations.
* 🎨 **Modern GUI:** Clean, responsive, and intuitive interface designed with Java Swing.

---

## 🛠️ Tech Stack & Prerequisites

* **Language:** Java (JDK 17 or higher recommended)
* **GUI Framework:** Java Swing
* **Database:** MySQL
* **Build Tool:** Apache Maven
* **Database Driver:** MySQL Connector/J (`mysql-connector-j`)
